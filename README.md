# מחולל ברכות — App Jam

תרגול אנדרואיד לפני החופש. עובדים בזוגות, 70 דקות קוד, ואז הצגה של 3 דקות לכל זוג.

האפליקציה: מסך ראשון שבו ממלאים שם, בוחרים סגנון ברכה וכותבים משפט אישי; מסך שני שמציג את כרטיס הברכה; רשימה של הברכות שנשמרו.

## התקנה (3 דקות)

1. הורידו את הקוד: `Code` → `Download ZIP`, או `git clone` אם אתם עובדים עם Git.
2. פתחו את התיקייה ב-Android Studio דרך `File` → `Open` (לא Import).
3. חכו ל-Gradle Sync שיסתיים ולחצו Run על אמולטור או על מכשיר.
4. האפליקציה תעלה ותציג את הטופס. הכפתור עדיין לא עושה כלום — זו העבודה שלכם.

אם ה-Sync נכשל: `File` → `Sync Project with Gradle Files`. אם עדיין נכשל — קראו לי, לא תקועים על זה יותר מ-5 דקות.

## מה כבר מוכן ומה עליכם לכתוב

מוכן: כל ה-layouts, המחלקה `Greeting`, הרישום ב-Manifest, ה-ViewHolder וחיבור ה-RecyclerView.

עליכם להשלים 7 מקומות המסומנים בקוד ב-`TODO`. חפשו אותם עם `Ctrl+F` או בחלון `TODO` למטה ב-Android Studio.

## כללי המשחק

- עובדים בזוגות, מחשב אחד, מתחלפים בהגה כל 15 דקות.
- מותר להיעזר בבינה מלאכותית כמאמן: להסביר שגיאה, להזכיר תחביר, להציע כיוון. אסור לבקש ממנה לכתוב את הקוד של ה-TODO במקומכם — בדיוק כמו בפרויקט הגמר.
- כשמשהו קורס: קוראים את ה-Logcat, מוצאים את השורה הראשונה עם שם הקובץ שלכם, ורק אחר כך שואלים.

## בהצגה (3 דקות)

1. מריצים את האפליקציה ומראים אותה עובדת.
2. אומרים לאיזה שלב הגעתם.
3. מספרים על באג אחד שנתקעתם בו ואיך פתרתם אותו.
